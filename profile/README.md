<h1 align="center">Comfortably Stuck</h1>

<p align="center">
  <b>Evaluation Pitfalls in Bench2Drive's Closed-Loop Protocol</b>
</p>

<p align="center">
  <a href="https://arxiv.org/abs/2610.21741">Paper</a>
  ·
  <a href="https://github.com/comfortably-stuck/comfortably-stuck.github.io">Project page source</a>
  ·
  <a href="https://github.com/comfortably-stuck/Bench2Drive-Comfort">Code</a>
</p>

This work examines how Bench2Drive's closed-loop protocol measures comfort
and supplies navigation signals. Its fixed-time comfort metric rewards
standing still, while controller steering and target-point sampling can
affect models differently. We introduce distance-based comfort scoring and
describe protocol corrections for navigation signals.
